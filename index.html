01 — ABOUT

What is this project?

This project demonstrates an end-to-end DevOps workflow for deploying a web application. Every code change is managed through GitHub and automatically processed through a CI/CD pipeline.

The application is containerized using Docker and deployed to an AWS cloud environment, demonstrating practical knowledge of automation, Linux and cloud infrastructure.
